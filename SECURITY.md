# Security Policy

## Supported versions

Security fixes target the latest release and the default branch.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting when enabled. Do not open a public issue containing exploit details, secrets, personal data, or confidential financial information.

## Data-safety boundary

This repository is designed for public or synthetic inputs. Do not connect it to live brokerage accounts, production order systems, customer data, or private document stores without an independent security and compliance review.

The demo makes no network requests and stores no credentials.
