# Provenance and Disclosure Policy

## Repository origin

This public repository is a clean, general implementation of an evidence-to-simulation pattern. It intentionally excludes employer-confidential materials, private links, real account data, corporate identity assets, production identifiers, and broker-specific rules.

The included formulas, events, parameter values, documents, claims, and account are synthetic teaching artifacts created for this repository.

## Evidence states

- `PUBLIC`: supported by a cited, publicly accessible, license-compatible source.
- `SYNTHETIC_VERIFIED`: an internally consistent educational artifact created for this repository.
- `DISPUTED`: sources conflict or interpretation is unresolved.
- `UNKNOWN`: provenance or meaning is incomplete.
- `REJECTED`: material must not participate in executable logic.

Only `PUBLIC` and `SYNTHETIC_VERIFIED` claims may support executable nodes in the current compiler.

## Contribution rule

If you cannot demonstrate that a rule is public, original, license-compatible, or explicitly authorized, do not submit it. Renaming an internal rule does not make it public.
